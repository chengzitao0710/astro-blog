# 分析

首先题目是个分组问题，要把字母按照字母的种类，分组完后，一个小组里面的字母可以通过随意排序，得到相同的结果。

---
# 题解

## 排序

根据分析我们很容易想到要排序，排序后才能进行分组。我们可以通过哈希表把排序后的结果作为键，然后把排序相同的字符串存同一个链表中。

> 时间复杂度$O(NKlogK)$，$N$值字符串的数量，$K$指单个字符串最大长度，每个字符串排序耗时$KlogK$。

### 代码

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (auto &s : strs) {
            string key = s;
            sort(key.begin(), key.end());
            mp[key].push_back(s);
        }
        vector<vector<string>> ans;
        for (auto &item : mp) {
            ans.push_back(item.second);
        }
        return ans;
    }
};
```

## 计数

小写字母只有26个，统计每个字母出现次数拼成字符串作为key，避免排序$KlogK$开销

>时间复杂度$O(NK)$

### 代码

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (const string& s : strs) {
            int cnt[26] = {0};
            for (char c : s) {
                cnt[c - 'a']++;
            }
            string key;
            for (int i = 0; i < 26; ++i) {
                key += to_string(cnt[i]) + '#';
            }
            mp[key].push_back(s);
        }
        vector<vector<string>> res;
        for (auto& p : mp) res.emplace_back(p.second);
        return res;
    }
};
```

- 注意：在每个字母计数间加上$#$ 是为了不让技术间互相影响，比如**a**的个数是1，**b**的个数是12，如果直接拼接，就是**112**，但是如果存在某个字符串**a**的个数是11，**b**的个数是2，那么拼接也是**112**，所以要加上间隔符。
