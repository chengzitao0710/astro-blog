# 题目

给定一个 `_m_ x _n_` 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用 **[原地](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 算法**。
**

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

**输入：** matrix = [[1,1,1],[1,0,1],[1,1,1]]
**输出：**[[1,0,1],[0,0,0],[1,0,1]]

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

**输入：** matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
**输出：**[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

# 题解

### 暴力

##### 核心思想

这个想法很直接，我们可以先遍历找出`0`的位置，然后通过点的位置取处理对应得**行**和**列**。

##### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        vector<pair<int, int>> pii;
        for(int i = 0; i < matrix.size(); i++) {
            for(int j = 0; j < matrix[i].size(); j++) {
                if(matrix[i][j] == 0) pii.push_back({i, j});
            }
        }
        for(auto &p: pii) {
            int x = p.first;
            int y = p.second;
            for(int i = 0; i < matrix[0].size(); i++) matrix[x][i] = 0;
            for(int i = 0; i < matrix.size(); i++) matrix[i][y] = 0;
        }
    }
};
```

> **时间复杂度：**$O(mn + k\cdot(m+n))$，k 为矩阵中原始 0 的个数。最坏全矩阵都是 0，$k=mn$，退化到 $O(mn(m+n))$，**效率很差**。
> **空间复杂度：**$O(k)$，存储所有 0 点坐标；最坏 $O(mn)$。

### 使用标记数组

##### 核心思想

这里不直接记录点，而是通过列数组和行数组来记录哪个位置是`0`，标记位置。

##### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        vector<bool> row(m), col(n);
        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(!matrix[i][j]) row[i] = col[j] = true;
            }
        }
        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if (row[i] || col[j]) matrix[i][j] = 0;
            }
        }
    }
};
```

> **时间复杂度：**$O(mn)$，两次完整遍历矩阵
> **空间复杂度：**$O(m + n)$，两个布尔数组

### 使用两个标记变量

##### 核心思想

复用矩阵**第一行、第一列**充当上面解法的 `row[]`、`col[]`标记数组，不新建数组。

**关键陷阱**

第一行本身、第一列本身也可能包含原始 0；

如果直接拿第一行第一列当标记，会覆盖掉原本的数据，因此需要**两个 bool 变量预先保存第一行、第一列是否含有原始 0**。

**执行步骤**

1. 预先检测：`firstRowZero`记录第一行是否原本有 0；`firstColZero`记录第一列是否原本有 0。
2. 从 `i=1,j=1`开始遍历矩阵主体：
    
    - 如果`matrix[i][j]==0`，把本行的第一列位置`matrix[i][0]`置 0（行标记），本列的第一行位置`matrix[0][j]`置 0（列标记）。
    
3. 根据第一行、第一列的标记，把矩阵主体区域置零（依旧跳过 i=0,j=0）。
4. 最后根据预先保存的`firstRowZero`、`firstColZero`，回填处理第一行、第一列。

##### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        bool firstRowZero = false, firstColZero = false;
		// 1.预先判断第一行、第一列本身是否存在0
        for(int j = 0; j < n; j++) {
            if(matrix[0][j] == 0) {
                firstRowZero = true;
                break;
            }
        }
        for(int i = 0; i < m; i++) {
            if(matrix[i][0] == 0) {
                firstColZero = true;
                break;
            }
        }
		// 2.利用第一行第一列做标记，跳过0行0列
        for(int i = 1; i < m; i++) {
            for(int j = 1; j < n; j++) {
                if(matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        //3.主体区域置零
        for(int i = 1; i < m; i++) {
            for(int j = 1; j < n; j++) {
                if(matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        //4.处理第一行
        if(firstRowZero) {
            for(int j = 0; j < n; j++) matrix[0][j] = 0;
        }
		//5.处理第一列
        if(firstColZero) {
            for(int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
};
```

> **时间复杂度：**$O(mn)$
> **空间复杂度：**$O(1)$，仅两个 bool 变量，复用原矩阵存储标记。

### 使用一个标记变量

##### 核心思想

- 只用 1 个布尔变量 `firstColZero`，专门记录**第一列原始是否存在 0**。
- **第一行是否有 0 不再额外变量**：直接使用矩阵的第一行 `matrix[0][...]` 充当标记。
- 遍历范围：行从 `i=0 ~ m-1`，**列从 `j=1` 开始（跳过第一列）**
    
    - 遇到 `matrix[i][j]==0`：`matrix[i][0]=0`（标记 i 行），`matrix[0][j]=0`（标记 j 列）
    
- ⚠️注意：**第一列原始 0 不能写进 matrix，只能存放在 `firstColZero`**，否则会污染标记。
- 置零顺序：**从右下角往左上角倒着遍历**，避免覆盖还没读取的标记信息。

##### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        // 仅1个标记变量：记录第一列原本是否存在0
        bool firstColZero = false;
        for(int i = 0; i < m; ++i) {
            // 单独判断第一列元素
            if(matrix[i][0] == 0) {
                firstColZero = true;
            }
            // j从1开始，跳过第一列
            for(int j = 1; j < n; ++j) {
                if(matrix[i][j] == 0) {
                    matrix[i][0] = 0;   // 标记第i行
                    matrix[0][j] = 0;   // 标记第j列
                }
            }
        }
        // 倒序遍历！从后往前，防止第一行标记被提前覆盖
        for(int i = m - 1; i >= 0; --i) {
            for(int j = n - 1; j >= 1; --j) {
                if(matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
            // 最后处理本行的第一列
            if(firstColZero) {
                matrix[i][0] = 0;
            }
        }
    }
};
```

> **时间复杂度：**$O(mn)$
> **空间复杂度：**$O(1)$，**只使用 1 个 bool 标记变量**

### 四种算法对比

|算法方案|核心做法|时间复杂度|空间复杂度|优点|缺点|面试评价|
|---|---|---|---|---|---|---|
|方案 1：保存零点坐标|遍历记下所有`(i,j)`零点，再对每个零点整行整列置 0|O(mn+k(m+n))<br><br>最坏O(mn(m+n))|O(k)，最坏O(mn)|逻辑最直白，上手快|零点多会大量重复置零，效率差|能 AC，**不推荐写**|
|方案 2：行列布尔数组|`row[]`、`col[]`分别标记哪些行、列需要清零，二次遍历置零|O(mn)|O(m+n)|代码简短，无坑，不容易写错|需要额外数组空间|⭐日常刷题首选|
|方案 3：原地‑双 bool 变量|复用第一行第一列做标记；两个变量保存第一行、第一列原始 0 状态|O(mn)|O(1)|空间最优，顺序遍历即可|边界条件较多，容易漏处理首行首列|⭐面试标准最优解|
|方案 4：原地‑单 bool 变量|仅 1 个变量保存第一列原始 0；**倒序遍历**防止标记被覆盖|O(mn)|O(1)|额外变量最少|必须倒序，逻辑绕，极易写错|面试官追问 “还能再少变量吗” 才写|
